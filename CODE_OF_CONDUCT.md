# Code of Conduct

## Our standard

We want this repository to be a welcoming place for people with different backgrounds and levels of experience. Be respectful, assume good intent, give actionable feedback, and focus criticism on ideas and code rather than people.

Examples of expected behavior include:

- Using inclusive and professional language.
- Respecting different viewpoints and experiences.
- Accepting constructive feedback gracefully.
- Giving credit for ideas and contributions.
- Protecting other people's privacy and confidential information.

Harassment, personal attacks, discriminatory language, deliberate intimidation, doxxing, and publication of private information are not acceptable.

## Scope

This standard applies to issues, pull requests, discussions, code review, and other project spaces. It also applies when someone represents the project in public.

## Reporting

Report conduct concerns privately to the repository owner through their GitHub profile. Do not post sensitive details in a public issue. Reports will be reviewed in good faith, with privacy respected as far as practical.

Project maintainers may edit or remove contributions and restrict participation when behavior is inconsistent with this standard.
